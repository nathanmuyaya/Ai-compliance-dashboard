# Ai-compliance-dashboard

A React + TypeScript dashboard for store sales reporting and flagged compliance risks.

## Features

- **Sales reports** — revenue trend over 7/30/90 days, revenue by category
- **Flagged risks** — table of flagged transactions with severity, status, and category filters

## Stack

Vite, React, TypeScript, Recharts.

## Getting started

```bash
npm install
npm run dev
```
